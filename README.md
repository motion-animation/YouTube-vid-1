# Tape Market — 87-Scene HTML + SFX + 1080p Parallel Video Pack

Ready-to-run faceless motion graphics video pack generated from `output.srt` (118 cues, 10m16s) in the clean Google/Apple Keynote light theme (`1920x1080` Full HD, 8x Parallel Matrix).

## What's Inside
- `scenes/scene_001.html` – `scenes/scene_087.html`: 87 fast-paced, zero-drift synced HTML scenes with continuous living motion, smooth entry/exit transitions, and clean floating subtitles.
- `sfx/`: 7 synthesized WAV sound effects (`whoosh.wav`, `pop.wav`, `click.wav`, `tick.wav`, `chime.wav`, `thud.wav`, `alert.wav`).
- `render.py`: Parallel `1080p` Playwright + FFmpeg chunk renderer & zero-drift audio mixer with direct Google Drive audio download.
- `.github/workflows/render.yml`: 8-way parallel GitHub Actions matrix workflow.
